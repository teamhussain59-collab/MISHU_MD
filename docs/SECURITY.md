# Security notes

- Never commit `.env`, WhatsApp auth state, API keys, passwords, cookies, or personal access tokens.
- Keep the bot owner-only unless a feature explicitly documents another access policy.
- Pair only an account whose owner is completing the pairing flow on their own device.
- Do not use unsolicited bulk messaging, spam, or account-access tricks.
- Use lawful, authorized media sources and respect copyright.
- Rotate any credential that has been pasted into a chat or public issue.
