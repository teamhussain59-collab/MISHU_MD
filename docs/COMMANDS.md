# MISHU MD commands

The initial release intentionally contains a small set of implemented commands.

| Command | Purpose |
| --- | --- |
| `.ping` | Check bot response |
| `.menu` / `.help` | Display implemented commands |
| `.quran <surah> <ayah>` | Urdu Quran translation from AlQuran Cloud |

Commands are owner-only. A command is documented only when its handler exists. More features will be added in tested groups; no dummy command list is used.
